# HTML/CSS — сайт кофейни «Зерно»

Учебный сайт кофейни-обжарочной: семь страниц по заданиям курса HTML/CSS — от семантической разметки до интерактивной версии.

## Страницы

| Файл | Задание |
|---|---|
| `site/02-semantic.html` | Семантический каркас |
| `site/03-styled.html` | Сложная стилизация |
| `site/04-menu.html` | Flexbox и Grid |
| `site/05-responsive.html` | Адаптивная вёрстка |
| `site/06-3d.html` | 3D-трансформации |
| `site/index.html` | Итоговая интерактивная страница |

Макет — `site/assets/wireframe.svg`, описание темы и стилей — `site/README.md`. Тексты ответов — `answers/01–07.md`.

## Запуск

```sh
cd site
python3 -m http.server 8000
```

Открыть http://localhost:8000/.
