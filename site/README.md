# Сайт «Зерно» — тема и структура

Учебный сайт кофейни-обжарочной «Зерно». Одна тема проходит через все 7 заданий дисциплины «HTML/CSS»: от семантического каркаса до интерактивной страницы.

## Тема

Сайт-визитка кофейни: меню, обжарка, отзывы, контакты, бронирование столика.

## Макет

Макет подготовлен самостоятельно: схема главной страницы — `assets/wireframe.svg`. Блоки: шапка, первый экран с иллюстрацией, «О нас» с цифрами, сетка меню, шаги обжарки, отзывы, контакты и форма брони.

## Оформление

- Палитра: фон `#f6efe3`, поверхность `#fffaf3`, текст `#2b1d16`, акцент `#b4642f`, доп. акцент `#c8873a`.
- Шрифты: системные — Palatino/Georgia для заголовков, system-ui для текста.
- Иллюстрации: три SVG в `assets/` (логотип, зёрна, чашка).

## Страницы

| Файл | Назначение |
|---|---|
| `02-semantic.html` | Задание 2: семантический каркас без CSS |
| `03-styled.html` | Задание 3: сложная стилизация макета |
| `04-menu.html` | Задание 4: каталог на Grid и Flexbox |
| `05-responsive.html` | Задание 5: адаптивная главная (mobile-first) |
| `06-3d.html` | Задание 6: 3D-трансформации |
| `index.html` | Задание 7: итоговая интерактивная страница |

Стили: `css/base.css` (общие), `styled.css`, `layout.css`, `responsive.css`, `demo3d.css`, `interactive.css` — по номеру задания.

## Запуск

Открыть `index.html` в браузере или поднять локальный сервер из этой папки:

```sh
python3 -m http.server 8000
```

Дальше — http://localhost:8000/.
